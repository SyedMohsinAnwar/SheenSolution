# SheenSolution Website

A responsive one-page promotional website for SheenSolution.

## Before publishing
1. Open `index.html`.
2. Replace `YOUR_EMAIL_HERE` with your real email.
3. If you want a WhatsApp button, replace the Contact button link with your WhatsApp link.

## Free hosting
This static site can be hosted on GitHub Pages. GitHub Pages supports custom domains, so your SheenSolution.com domain can be connected later.
